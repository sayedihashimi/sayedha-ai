# Gemini Notes Cleanup

## What this does

Google Docs notes generated by Gemini paste into Obsidian with a lot of cruft:
stray `**` wrappers, checkbox images encoded as base64, feedback/survey prompts,
and whitespace-only filler lines with odd indentation. This skill converts that
paste into clean Markdown ready for Obsidian.

**Core principle: this is a FORMATTING cleanup only.** Never reword, summarize,
reorder, or paraphrase the note content. Every sentence, link, timestamp, name,
and heading stays exactly as written. Only formatting noise is removed.

## When to use

Trigger when the user pastes meeting notes (often starting/ending with `**`,
containing `### Summary` / `### Decisions` / `### Next steps` / `### Details`
sections, `data:image/...` blobs, or Google Docs links) and wants them cleaned,
or explicitly asks to tidy Gemini / Google Docs notes for Obsidian.

## Cleanup rules

Apply all of these:

1. **Remove stray bold wrappers.** Delete any line that consists only of `**`
   (Gemini wraps the whole note in bold; these usually appear as the first and
   last lines).

2. **Remove Gemini boilerplate and feedback prompts** wherever they appear,
   including:
   - "We've updated the … section using your feedback." (any "We've updated …
     using your feedback" sentence)
   - "Let us know what you think: [Helpful](…) or [Not Helpful](…)"
   - "Did the screenshots in this section make your notes [better](…) or
     [worse](…)?"
   - Any leftover survey line linking to `google.qualtrics.com` or the
     `goo.gle` feedback links.

3. **Remove checkbox images and promote the task text.** In "Next steps",
   Gemini renders each task's checkbox as an image on its own line, e.g.
   `![unchecked](data:image/…)` or `- ![checked](data:image/…)`, followed by
   the indented task text. Delete the checkbox-image line and turn the task
   text into a single top-level bullet, preserving the `[Owner]` prefix and the
   wording verbatim:

   ```
   - [Sayed Hashimi] Create product brief: Draft a product brief regarding …
   ```

4. **Keep real content screenshots verbatim.** Images written as
   `![](data:image/…)` (empty alt text) are genuine screenshots from the notes.
   Preserve them exactly, including the full base64 data — do NOT drop or
   truncate them. Only the checkbox images from rule 3 are removed.

5. **Fix whitespace.**
   - Delete whitespace-only "filler" lines that Gemini inserts between list
     items and around sections.
   - Delete the extra leading indentation Gemini adds to list items and their
     continuation lines.
   - Strip trailing spaces from lines, **except** the intentional Markdown hard
     breaks (two trailing spaces) inside the **Summary** block — leave the
     Summary's paragraph/line-break structure intact.
   - Result spacing: no blank line before a heading; exactly one blank line
     after each `###` heading; no blank lines between consecutive bullet points.

6. **Normalize headings.** A heading starts at the beginning of the line
   (`### Summary`, not `  ### Summary`).

7. **Change nothing else.** Links, timestamps like `([00:01:33](…))`, names,
   and all body text are copied through unchanged.

## Output

Return **only** the cleaned Markdown, inside a single fenced code block, so it
can be copied straight into Obsidian. Do not add commentary before or after
unless the user asks. If the note contained content screenshots, keep them in
place in the output.

## Optional: run the script (tool-enabled environments)

If you can execute code (e.g. Cowork or Claude Code), you can apply the rules
deterministically instead of by hand. Save the pasted text to a file and run:

```bash
python scripts/clean_notes.py input.md output.md
# or pipe:  cat input.md | python scripts/clean_notes.py
```

`scripts/clean_notes.py` implements every rule above. In a plain chat without
code execution, just apply the rules directly to the pasted text.

## Before / after example

Input (abbreviated):

```
**

### Next steps

- ![unchecked](data:image/png;base64,iVBORw0KG…)

    [Sayed Hashimi] Create product brief: Draft a product brief regarding ultimate attribution.

We've updated the Decisions section using your feedback.

Let us know what you think: [Helpful](https://google.qualtrics.com/…) or [Not Helpful](https://google.qualtrics.com/…)
**
```

Output:

```
### Next steps
- [Sayed Hashimi] Create product brief: Draft a product brief regarding ultimate attribution.
```
